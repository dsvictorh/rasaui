# RasaUI
Blank slate UI library for web projects.

## Development Prerequisites
### Runtimes
- Node.js (v26+)

## Goblal NPM Packages
- @angular/cli (v22+)

### VSCode Extensions
- [Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode)
- [Angular Language Service](https://marketplace.visualstudio.com/items?itemName=Angular.ng-template)

## Supported Frameworks
- [Angular](angular/)

### Maintenance & Features
All work done in the library needs to be supported by all the list frameworks. PRs without fixes for all of them or with references to other PRs per framework should be immediately rejected.

### Naming Convention
All folders and files need to be formatted with lowercase letters separated by hyphens in between words and/or respect the rules, suffixes and prefixes described in every framework's README.
